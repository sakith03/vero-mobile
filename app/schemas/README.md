# Room schema history

`com.example.veromobile.data.local.AppDatabase/3.json` is generated by Room 2.7.1 through KSP. Retain each generated version when the database changes.

Versions 1 and 2 had `exportSchema = false`; no historical JSON exports are available. They have not been reconstructed or fabricated here. Migration regression fixtures use the historical entity definitions instead:

- `336437f`: version 1, Expense only.
- `2cfd966`: version 2, Expense, Savings Goal and Goal Contribution.
- `e210320`: version 2, those tables plus Income.

The two version-2 variants share a version number but have different schemas. Both upgrade to version 3 through `MIGRATION_2_3`. Existing `MIGRATION_1_2` remains unchanged.
